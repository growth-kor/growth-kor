#### 👁️ [eye](https://github.com/growth-kor/eye) ｜ [🌐 바로가기](https://growth-kor.github.io/eye/)
* **🛠️ 기술 스택:**    
* **📝 한줄 소개:** 사용자의 마우스 커서와 화면 속 텍스트를 실시간으로 집요하게 추적 및 감시하는 인터랙티브 사이버펑크 아스키 아트 웹 애플리케이션입니다.
* **💡 주요 특징:** 순수 삼각함수(코사인 돔 궤적)로 렌더링된 3D 유기적 아몬드 눈동자, 실시간 마우스 커서 360도 스무스 추적 및 생체 리듬 눈 깜빡임, 고전 DVD 로고 스타일로 화면 사방을 영구 바운스 유영하는 'I'M WATCHING YOU' 텍스트 패널 및 유휴 시 자동 텍스트 응시 모드,  키(한글 'ㄹ' 자판 완벽 호환) 전체화면 토글, 초 아래 밀리초 2자리 실시간 디지털 시계, 그리고 맥북 화면 꺼짐/잠자기 모드를 원천 방어하는  시스템을 갖추고 있습니다.

#### 🤖 [anino](https://github.com/growth-kor/anino) ｜ [🌐 바로가기](https://growth-kor.github.io/anino/)
* **🛠️ 기술 스택:**   
* **📝 한줄 소개:** 아두이노(Arduino) 인터랙티브 학습을 위한 가상 하드웨어 시뮬레이터입니다. 
* **💡 주요 특징:** 사용자의 학습 단계에 맞춘 레벨별/일차별 코스를 제공하며, 웹 브라우저 내에서 직접 하드웨어를 제어해 볼 수 있는 시뮬레이션 엔진이 설계되어 있습니다.

#### 🪐 [CosmoSpace](https://github.com/growth-kor/CosmoSpace) ｜ [🌐 바로가기](https://growth-kor.github.io/CosmoSpace/)
* **🛠️ 기술 스택:**    
* **📝 한줄 소개:** 수천 장의 로컬 사진 폴더를 웹 브라우저 안에서 멈춤 없이 3D 우주 은하계 행성계로 펼쳐내는 차세대 인터랙티브 포토 스페이스입니다.
* **💡 주요 특징:** 피보나치 구면 알고리즘 기반의 겹침 0% 3D 폴더 행성계 배치, 100% 클라이언트 인메모리 고속 압축으로 VRAM 누수 없이 부드러운 60fps 탐색을 지원하며, 3대 차원 레이아웃(Galaxy/Sphere/Grid) 실시간 전환, WASD 심우주 자유 비행, 원본 LRU-10 캐시 및 고조 사토루 영역전개 사운드 시스템을 갖추고 있습니다.
